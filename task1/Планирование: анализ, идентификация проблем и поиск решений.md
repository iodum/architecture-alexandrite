## Проблемные места
- Потеря заказов
- Проблемы с загрузкой новых заказов
- Длительная обработка моделей
- Высокая нагрузка на MES API
- Ограниченная пропускная способность RabbitMQ
- Отсутствие мониторинга и логирования
- Частичная реализация CI/CD процессов
- Отсутствие автотестов
- Отсутствие единого места, где можно посмотреть статус заказа
- Не предусмотрена отказоустойчивость
- Задержки релизов


## Инициативы для устранения нежелательных ситуаций

1. **Внедрение мониторинга, логирования, трассировки** 
   - Для решения проблем необходимо знать в каких местах и при каких условиях происходят сбои, без мониторинга установить это не получится
   
2. **Масштабирование MES**
   - Самая загруженная точка системы
   - Необходимо разделить на сервисы, добавить еще экземпляры и реплицировать БД
   
3. **Полная автоматизация CI/CD процессов**
    - Для устранения проблем ручного деплоя
   
4. Создание сервиса для отслеживания заказов
    - Поможет хранить и получать данные о статусе заказе в одном места, с репликацией Master-Slave ускорится загрузка дашборда заказов 

5. Написание автотестов
    - Минимизация человеческого фактора при тестировании
    - Ускорение выпуска релизов
   
6. Расширение команды
    - Могут понадобиться еще люди для быстрого обновления системы
